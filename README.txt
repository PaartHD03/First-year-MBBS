# Suhani's First MBBS Study Hub

## Deploy to Netlify
1. Extract `Suhani_First_MBBS_Study_Hub.zip`.
2. Open https://app.netlify.com/drop
3. Drag the extracted `suhani_mbbs_hub` folder (the folder containing `index.html`) onto the page.
4. Netlify will publish it and give you a public URL. You can rename the site in Netlify site settings.

## Customise
- Edit `index.html` to change the name, wording, links, study topics or theme.
- The Telegram link is the exact link supplied by the site owner. It may be private and require Telegram membership/login.
- Progress checkboxes are saved in the visitor's browser using localStorage. They do not sync between devices or browsers.

## Important
This is a student-made learning roadmap, not an official T.S. Misra syllabus. Verify the exact admission-batch syllabus, teaching plan, practicals and exam pattern with the college. Use only legally shared learning materials; this site does not host textbook files.
